# Приём заявок: Google-таблица + Telegram

Квиз на сайте отправляет заявку в Google Apps Script (`Code.gs`). Скрипт:

1. пишет строку в лист «Заявки» — это мини-CRM: статус, заметки, источник рекламы;
2. присылает сообщение в Telegram с кнопкой «💬 WhatsApp» — приветствие клиенту уже написано, ответ в 2 касания;
3. когда подключён маркер Meta — отправляет событие `Lead` в Conversions API (тот же `event_id`, что у пикселя, Meta склеивает пару).

Токены хранятся в свойствах скрипта, не в коде: сайт и этот файл публичны.
Telegram недоступен — заявка уходит письмом владельцу таблицы, в таблице она есть в любом случае.

Защита: скрытое поле-ловушка, «квиз быстрее 3 секунд», не больше 20 заявок в минуту, повтор той же отправки
(`event_id`) не записывается дважды, текст «=…» в ячейке не становится формулой.

## Установка — один раз, ~10 минут

### 1. Бот для заявок
1. Telegram → **@BotFather** → `/mybots` → **@BeautyMafiaAcademy_bot** → **API Token** → скопировать.
   Можно и новый: `/newbot`, например «BM Заявки».
2. Откройте этого бота и нажмите **Start**. Для группы — добавьте бота в группу и напишите там любое сообщение.

### 2. Таблица и скрипт
1. Откройте **sheets.new** — создастся пустая таблица. Назовите её «Beauty Mafia — Заявки».
2. Меню **Расширения → Apps Script**.
3. Удалите код в редакторе и вставьте весь `Code.gs`:
   https://github.com/MaksimMaverick/beauty-mafia-academy/blob/main/apps-script/Code.gs → кнопка «Copy raw file».
   Сохраните (Ctrl+S).
4. **Начать развёртывание → Новое развёртывание** → шестерёнка → **Веб-приложение**:
   - Запуск от имени: **Я**;
   - У кого есть доступ: **Все**.

   **Начать развёртывание → Предоставить доступ** → ваш аккаунт → «Дополнительные настройки» →
   «Перейти на страницу проекта» → **Разрешить**. Google так предупреждает о любом личном скрипте.
5. Скопируйте **URL веб-приложения** (заканчивается на `/exec`). Он не секретный — его вписывают в сайт:
   `index.html` → `CFG.leadsUrl`.

### 3. Подключить Telegram
1. Вернитесь в таблицу и обновите страницу — появится меню **Beauty Mafia**.
2. **1. Подготовить таблицу**.
3. **2. Подключить Telegram** → вставить токен → бот пришлёт «✅ Заявки … будут приходить сюда».
4. **3. Тестовая заявка** → в Telegram придёт тест, в таблице появится строка со статусом «Тест».

### 4. Meta Conversions API (когда будете готовы)
Events Manager → пиксель `1012135685120190` → Настройки → Conversions API → «Создать маркер доступа».
Таблица → **Beauty Mafia → Подключить Meta** → вставить маркер. Для проверки можно указать код из
«Тестирования событий», потом подключить ещё раз без кода.

## Если поменяли код скрипта
Apps Script → **Начать развёртывание → Управление развёртываниями** → ✏ → Версия: **Новая версия** → **Развернуть**.
Адрес `/exec` не меняется, сайт править не нужно.

## Лид-формы Instagram (позже)
Make.com, бесплатный тариф: «Facebook Lead Ads → Watch leads» → «HTTP → Make a request», `POST` на адрес `/exec`,
тело JSON — `{"name": "…", "phone": "…", "pref": "WhatsApp", "plan": "Лид-форма Instagram", "utm": {"source": "meta_form"}}`.
Заявка попадёт в ту же таблицу и тот же Telegram.
