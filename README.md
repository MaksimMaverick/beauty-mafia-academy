# Beauty Mafia Hair Academy

Лендинг академии обучения лечению и модификации волос (кератин, ботокс, реконструкция). Обучение очно в Чикаго,
ученики — из всех штатов США. Сайт: https://beautymafia.academy/ (GitHub Pages, ветка `main`, корень).

## Как обновить сайт
1. Перед правкой — `git pull` (текст правят и прямо на GitHub).
2. Отредактируйте `index.html` (или замените картинки в `images/`).
3. Запушьте изменения — GitHub Pages обновится автоматически за 1–2 минуты.

## Что где
- **Квиз** вместо формы: 6 вопросов → контакты → подборка формата. Открывают его все кнопки с `data-quiz`
  (`data-plan="group|individual|mentor|salon"` пропускает вопрос о формате). Ссылка для рекламы сразу в квиз:
  `https://beautymafia.academy/?quiz=1` (или `#quiz`), с форматом — `?quiz=1&plan=salon`.
- **Заявки** уходят в Google Apps Script → Google-таблица + Telegram (+ Meta Conversions API).
  Код и установка — `apps-script/`. Адрес веб-приложения — `CFG.leadsUrl` в начале `<script>` в `index.html`.
  Токенов в коде сайта нет и быть не должно: сайт публичный.
- **Цены 2026** и зачёркнутые цены 2027 — в карточках `#pricing`, в квизе (`PLANS`) и в FAQ. Дедлайн — `CFG.deadline`:
  после него таймер и зачёркнутые цены прячутся сами, а цены нужно действительно поднять (или объявить новую дату) —
  «старая цена», которой не было, — это нарушение правил FTC о скидках.
- **Пиксель Meta** `1012135685120190` — в `<head>`. События: `PageView`, `ViewContent` (цены), `Contact` (клики по
  контактам), `Lead` (заявка с квиза, `eventID` совпадает с серверным), свои — `QuizStart`, `GiftOpen`.
- **Подарок** (кнопка слева внизу) открывает плашку и ведёт в квиз; отметка «закреплён» хранится в браузере.
- **Политика конфиденциальности** — `privacy/` (RU + UA). Её же указывать в лид-формах Meta.
- **Вебинар** снят: `webinar/` перенаправляет на главную (с сохранением меток). Прежняя страница — в истории git.

## Языки: русский и украинский
Русский — исходный текст страницы. Украинский — словарь `i18n/uk.js` (белый список строк), собирается из
`i18n/uk.tsv` (RU<TAB>UA). Переключатель RU/UA в шапке, ссылка на украинскую версию — `?lang=uk`.
Отзывы (`data-noi18n`) не переводятся. После правки текста на странице:
1. `python tools/i18n.py extract` → `i18n/todo.txt` — новые строки без перевода;
2. перевести их в файл в том же порядке → `python tools/i18n.py pair файл`;
3. `python tools/i18n.py build` → и поднять `CFG.i18n` в `index.html` (сброс кэша).
Непереведённая строка просто остаётся русской — страница не ломается.

## Видео-отзывы (YouTube)
Ссылки на ролики задаются в списке `YT_REVIEWS` в начале тега `<script>` в `index.html`.
Вставьте ссылку YouTube (`youtu.be/…`, `watch?v=…`, `shorts/…` или ID) в поле `url`.
Пустой `url` = карточка «Скоро». Подробно — в `Как-обновить-видео-отзывы.txt`.
